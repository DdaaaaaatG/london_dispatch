# 레이아웃 템플릿

- 화면은 두 개(rooms · chat)뿐이고 전부 **폭 390px · 높이 약 565px**(저쪽 패널 640 − 헤더 75) 안에서 산다. 카탈로그는 작다. 여기 없는 구조는 ui-layout-designer가 웹 검색·자체 구성으로 만들고, 재사용 가치가 있으면 `.claude/skills/layout-pool/`에 저장한다(사용자 승인).
- 모든 ASCII는 정렬 불변식을 지킨다: 한글·전각 2칸, ASCII·박스 문자 1칸, 이모지 금지, 박스 안 줄 표시폭 동일. 폭은 **48칸**으로 통일(390px 비례).
- 세로는 flex로 채운다. 고정 px 높이는 상단 바·하단 바에만.

---

## 선택 가이드

| 화면 상황 | 패턴 |
|---|---|
| 항목을 골라 들어가는 목록(방 목록) | **L1 목록형** |
| 시간순 메시지 + 하단 입력 | **C1 대화형** |
| 항목 하나에 대한 2~4개 동작 선택, 파괴 조작 확인 | **S1 바텀시트** (L1·C1 위에 겹침) |
| 긴 텍스트 하나를 읽고 고침(장기기억) | **M1 메모리 편집** (C1의 ⋯ 메뉴에서 진입, 전체 덮음) |

- 기본 추천: rooms = **L1 + S1**, chat = **C1 + S1 + M1**.

## L1. 목록형 (방 목록)

```
+----------------------------------------------+
| ROOMS                              [+ 새 방] |
+----------------------------------------------+
| 10.05  티타임                                |
|        세바스찬: 예, 도련님.                 |
+----------------------------------------------+
| 10.03  체스 대결                             |
|        시엘: ...체스판 가져와.               |
+----------------------------------------------+
| 09.30  비 오는 밤                            |
|        (아직 대화 없음)                      |
+----------------------------------------------+
|                                              |
|          (빈 상태: 아직 방이 없습니다)       |
|                                              |
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 상단 바 | 화면 이름 · 새 방(토큰 있을 때만 렌더) | `TopBar`, `Button` | — |
| 목록 | 방 행(날짜·제목·마지막 발화). 탭/Enter 진입, 롱프레스/우클릭 → S1 | `ListRow` | `listRooms()` |
| 빈 상태 | 안내 한 줄 (+ 새 방 유도) | `EmptyState` | — |

- 구현 힌트: 상단 바 44px 고정, 목록 `overflow-y: auto; flex: 1`. 새 방 제목 입력은 상단 바 아래 인라인 행(기본값 오늘 날짜) — 별도 화면 금지. 행 높이 56px, 터치 타깃 ≥ 44px. 정렬 `updatedAt` 내림차순. 토큰 없으면 `[+ 새 방]`·롱프레스 메뉴 미렌더.

## C1. 대화형 (대화 화면)

```
+----------------------------------------------+
| <  티타임                 2026.10.05     ... |
+----------------------------------------------+
| (o) 시엘                           16:40     |
|     세바스찬, 홍차.                          |
|                                              |
|                  16:41        세바스찬 (o)   |
|                       예, 도련님.            |
|                                              |
|  - 지시 (SIBI) 둘이 체스 둬라 -              |
|                                              |
| (o) 시엘                           16:42     |
|     ...체스판 가져와.                        |
|                                              |
| (o) 세바스찬                   ...           |   <- 생성 중 임시 말풍선
|                        [새 메시지 v]         |   <- 위에 있을 때만
+----------------------------------------------+
| (세바스찬) (시엘)               [OOC: off]   |
| [ 지시나 대사를 입력...              ] [전송] |
+----------------------------------------------+
```

토큰 없음(읽기 전용) 판:

```
+----------------------------------------------+
| <  티타임                 2026.10.05         |
+----------------------------------------------+
|  ... 히스토리 동일 ...                       |
|                                              |
|   열람 전용입니다. 대화 참여는 회원만 가능.  |
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 상단 바 | 뒤로 · 방제 · 날짜 · ⋯(이름 변경·장기기억·삭제, 토큰 있을 때만) | `TopBar`, `IconButton` | 방 정보 |
| 히스토리 | 말풍선(화자별 정렬·아바타·시각), 생성 중 임시 말풍선, 위로 스크롤 페이지네이션, 새 메시지 배지. `role="log" aria-live="polite"` | `Bubble`, `NewMessageBadge` | `listMessages()` |
| 하단 바 | 캐릭터 버튼 2 · OOC 토글 · 입력창 · 전송. **토큰 없으면 전체 미렌더** | `Button`, `Toggle`, `TextArea` | `speak()`, `appendUser()` |

- 구현 힌트: 상단 바 44px, 하단 바 2행(버튼 행 40px + 입력 행 자동 높이 ≤ 3줄). 캐릭터 발화는 화자별 좌/우 정렬(시엘 좌, 세바스찬 우) — 색은 `ui_design_concept.md` 토큰. 유저/OOC는 중앙 회색 한 줄. 생성 중엔 캐릭터 버튼·전송 잠금, 입력은 허용. 스크롤 규칙은 `ui-design-strategy` §6.4. 말풍선 롱프레스/우클릭 → S1.

## S1. 바텀시트 / 컨텍스트 메뉴

```
+----------------------------------------------+
|  (뒤 화면, 반투명 덮개 — 탭하면 닫힘)        |
|                                              |
|                                              |
+----------------------------------------------+
|  세바스찬 · 16:41 "예, 도련님."              |
+----------------------------------------------+
|  수정                                        |
|  재작성                                      |   <- 마지막 캐릭터 발화일 때만
|  삭제                                        |   <- danger 색
+----------------------------------------------+
|  취소                                        |
+----------------------------------------------+
```

확인(confirm) 변형:

```
+----------------------------------------------+
|  이 메시지를 삭제할까요?                     |
|  되돌릴 수 없습니다.                         |
+----------------------------------------------+
|  [ 취소 ]                      [ 삭제 ]      |
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 덮개 | 바깥 탭·`Esc`로 닫기, 포커스 트랩 | `BottomSheet` | — |
| 머리 | 대상 요약 한 줄 | — | 메시지/방 |
| 항목 | 동작 목록(조건 안 맞는 항목은 미렌더) | `SheetItem` | — |
| 확인 | 2버튼, 파괴 버튼은 danger + 오른쪽 | `ConfirmDialog` | — |

- 구현 힌트: 시트 높이는 내용만큼, 최대 60%. 열릴 때 첫 항목에 포커스, 닫히면 트리거로 복귀. 브라우저 `window.confirm` 금지. 하나의 `BottomSheet` 컴포넌트를 메뉴·확인 두 변형으로 쓴다.

## M1. 메모리 편집 (장기기억)

```
+----------------------------------------------+
| <  장기기억 · 티타임                [저장]   |
+----------------------------------------------+
| 마지막 갱신 2026.10.05 16:30 · 자동 요약     |
+----------------------------------------------+
| +------------------------------------------+ |
| | 시엘은 체스 대결을 제안했고 세바스찬은   | |
| | ...                                      | |
| |                                          | |
| |                                          | |
| +------------------------------------------+ |
|                                   1,240/8000 |
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 상단 바 | 뒤로(변경 있으면 confirm) · 저장 | `TopBar`, `Button` | — |
| 메타 | 갱신 시각·출처(자동/수동) | `MetaLine` | `getMemory()` |
| 편집 | 전체 높이 textarea, 글자 수 | `TextArea` | `putMemory()` |

- 구현 힌트: C1 상단 ⋯ 메뉴에서 진입, 전체 화면을 덮는 뷰(모달 아님). 저장 성공 시 C1로 복귀 + 토스트 한 줄. 토큰 없으면 진입 경로 자체가 없다.

## 반응형·크기 변화

- 폭 < 390(저쪽 패널이 모바일에서 가로 전체일 때 ≥ 328): 말풍선 최대 폭 85%, 상단 바 날짜 생략, 캐릭터 버튼 아이콘+짧은 라벨.
- 높이 < 480: 하단 바 입력 행 1줄 고정, 히스토리 우선.
- 세로 공간은 항상 `100dvh`가 아니라 **부모 iframe 높이**(`html, body, #root { height: 100% }`)를 따른다.

## 풀 저장 규칙

- 위 카탈로그에 없는 구조를 새로 만들었고 재사용 가치가 있으면 ui-layout-designer가 `.claude/skills/layout-pool/SKILL.md`에 엔트리로 append한다(사용자 승인 후). 엔트리: 이름 / 용도 / ASCII / 영역 표 / 출처 / 최초 등록 화면.
