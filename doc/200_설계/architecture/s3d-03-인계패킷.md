## 1. server 패킷 — server-designer → server-implementer

요구: R-AUTH-004 · R-LLM-003·006 · R-MSG-003·009 · R-LLM-008 · R-NFR-001. 근거 02 §1·§3·§4.

**설계 문서(server-designer).**
- `llm.md`: §7.1 유저 줄 `[어떠한 의지]`·GUARD 3번째 줄 · 신규 절 "화자 선택"(02 §3.1 문구 확정, 파싱 벡터 6, 기본 화자 3, 66초 분할) · 선택 호출 usage 누적.
- `messages.md`: speak 판정 순서에 `'auto'` 분기(잠금 안에서 선택 → 발화) · 로그 `speak_done{…, auto, selected}`·`speaker_select_fallback{roomId, reason}`(본문·이름 미기록) · SRV-T-142 개정.
- `db.md`: `toMessage` 투영(유저 → `USER_DISPLAY_NAME`, 그 밖 `null`), `author_name`은 저장만.

| 파일 (server-implementer) | 변경 |
|---|---|
| `server/src/db/messages.ts` | `toMessage` 투영 |
| `server/src/llm/prompt.ts` | `userLabel`·`safeName` 제거, `PromptMessage`에서 `authorName` 제거, GUARD 3번째 줄 |
| `server/src/llm/select.ts`(신규) | `buildSelectPrompt` · `parseSpeakerChoice` · `fallbackSpeaker`(순수) |
| `server/src/llm/client.ts` · `index.ts` | 선택 호출(8초·재시도 없음·usage 누적)과 남은 예산 발화 호출 옵션 · export |
| `server/src/messages/generate.ts` | `'auto'`면 선택 → 발화. 50줄 넘으면 함수 추출 |
| `server/test/*` | 02 §6 + `llm-select.test.ts` 신규 |

**공개 시그니처(contract 전제).** `messages.speak(roomId, input: SpeakBody, background): Promise<Message>`, `SpeakBody.character: SpeakTarget`. 반환 `speaker`는 늘 `CharacterId`. 새 에러 코드·서비스 메서드·env 키·마이그레이션은 0이다.

**수용 기준.**
- `npx vitest run --project server` PASS · `npx tsc --noEmit -p server` exit 0.
- 유저 메시지 응답 `authorName`이 전부 「어떠한 의지」다(실명 저장 행을 GET으로 읽어도). D1 `author_name`은 실명이다.
- 프롬프트에 `authorName` 문자열 0회(센티넬).
- `'auto'`: 선택 각본 `ciel` → ciel · `모르겠다` → 기본 화자 · 선택 타임아웃 → 기본 화자 뒤 발화 성공 · usage 2건 · 예산 초과면 호출 0 · 같은 방 409.
- fake timer로 선택 8초 + 발화 재시도가 66초 안.
- 기존 speak·regenerate 테스트는 유저 라벨 단언 외 무수정 통과.
