## 3. 입장 시트 — PromptSheet 재사용

rooms(잠긴 행 탭, 02 §6.1 ③④)와 chat(입장 재요구, §5.4)이 **같은 컴포넌트**를 쓴다.

```
+----------------------------------------------+
| (뒤 화면: 반투명 덮개, 탭하면 닫힘)          |
|                                              |
|                                              |
+----------------------------------------------+
| 비밀번호                                     |  제목 h2 (약 20 + 아래 12)
| [****                                  4/64] |  TextInput password 36
| 비밀번호가 맞지 않습니다.                    |  role=alert 한 줄 (8 + 약 17)
| [  취소  ]                        [  입장  ] |  Button lg 44 × 2, 양끝 정렬
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 | 토큰 필요 |
|---|---|---|---|---|
| 덮개 | 바깥 탭·Esc = 취소(요청 중엔 막힘 — PromptSheet `isBusy` 기존 동작) | BottomSheet(PromptSheet 내부) | — | ✕ |
| 제목 | 「비밀번호」 | PromptSheet `title` | — | ✕ |
| 입력 | password, 시트 열릴 때 포커스, Enter = 입장 | TextInput(`inputType='password'` 델타) | — | ✕ |
| alert 줄 | 틀림 · 횟수 초과(초) · 연결 실패. 없으면 미렌더(줄 자리 없음) | PromptSheet `errorText` | `ROOM_PASSWORD_WRONG`·`RATE_LIMITED`·`NETWORK` | ✕ |
| 버튼 | 취소(왼쪽) · 입장(오른쪽 primary) | PromptSheet 버튼 줄 | `enterRoom(id, password)` | ✕ |

- 높이: 문구 없음 약 160px(padding 16 + 32 + 36 + 16 + 44 + 16), 문구 1줄 약 185px, 2줄 약 202px. 최대 70% 안.
- 모바일 키보드로 iframe 높이가 줄어도 시트는 아래에 붙고 덮개만 줄어든다.

## 4. ListRow 잠긴 변형

```
+----------------------------------------------+
| 티타임                                 10.05 |  안 잠김 — 지금 그대로(제목 · MM.DD)
+----------------------------------------------+
| [L] 비밀 다과회                              |  잠김 — 자물쇠 16 + 간격 8 + 제목, 날짜 DOM 없음
+----------------------------------------------+
```

| 항목 | 안 잠김(불변) | 잠김 |
|---|---|---|
| 자식 | 제목(flex 1) · 날짜(flex none, 약 30px) | 자물쇠(16×16, `aria-hidden`, muted 색) · 제목(flex 1) |
| 행 높이 | 56 | 56 |
| 제목 말줄임 폭 390px(내용 358) | 358 − 12(gap) − 30 = **316** | 358 − 16 − 8 = **334** |
| 제목 말줄임 폭 328px 패널(내용 296) | **254** | **272** |
| 접근성 이름 | (지금 규칙) | `"{제목}, 잠긴 방"` — 날짜 없음 |

- 자물쇠와 제목은 한 묶음(간격 `--space-2` 8px)으로 붙인다. 행 루트의 gap 12를 그대로 쓰면 자물쇠가 제목에서 떠 보인다.
- 잠긴 행의 제목 시작선은 안 잠긴 행보다 24px 오른쪽이다. 정렬을 맞추려고 안 잠긴 행에 빈 자리를 두지 않는다(요구 없음 — 지금 행 불변).
- 자물쇠 그림은 ListRow 로컬 장식(인라인 SVG 권장, 이모지 금지). IconButton 아이콘 목록과 무관.

## 5. chat 잠금

### 5.1 ⋯ 방 메뉴 — 5항목 판 (토큰 있을 때만, 규칙 불변)

```
+----------------------------------------------+
| 방 메뉴 . 티타임                             |  머리 40
| 이름 변경                                    |  44
| 장기기억                                     |  44
| 잠금                                         |  44  (S6 신규, 장기기억과 방 삭제 사이)
| 방 삭제                                      |  44  danger
| 취소                                         |  44
+----------------------------------------------+
```

- 높이 약 292px(16 + 40 + 44×5 + 16) = 565의 약 52%, 최대 70%(395) 안. 「잠금」 항목 이름은 방 상태와 무관하게 같다.
- 「잠금」 → 안 잠긴 방이면 §5.2, 잠긴 방이면 §5.3.

### 5.2 안 잠긴 방 → 「비밀번호 걸기」 (PromptSheet)

```
+----------------------------------------------+
| 비밀번호 걸기                                |  제목 h2
| [6자 이상 권장                         0/32] |  TextInput password, placeholder (보완)
| (실패 문구 한 줄 — 있을 때만)                |  role=alert
| [  취소  ]                        [ 잠그기 ] |  Button lg 44 × 2
+----------------------------------------------+
```

- 「6자 이상 권장」 안내는 **입력 placeholder 한 자리**로 둔다(줄 추가 없음). 실물 `PromptSheet`에는 placeholder 전달 prop이 없다 → ui-designer가 공용 델타로 정할 것(§8 주의점 1).
- 「비밀번호 바꾸기」(§5.3)도 같은 틀, 제목·저장 버튼 문구만 다르다.

## 7. 크기 변화 메모

- 폭 > 390(모바일 가로 꽉 참): B1·B2 입력과 행 제목만 늘어난다. 버튼 72·자물쇠 16·날짜 칸은 고정. 480 이상 콘텐츠 최대 폭 480 중앙(불변).
- 폭 < 354(패널): B2 placeholder 끝이 잘리기 시작(328에서 약 26px 부족, 「권장」 끝 글자). 입력값 자체는 문제없다.
- 높이 감소(키보드): rooms A 44 · B 96 고정, 목록만 줄어든다(높이 300이면 목록 160). 시트는 내용 높이·최대 70%. chat은 기존 규칙(히스토리만 축소) 불변.

## 8. ui-designer 주의점

1. **PromptSheet에 placeholder 전달 prop이 없다.** 02 §6.4 델타는 `inputType`뿐이다. §5.2 안내 자리를 쓰려면 `placeholder?`를 공용 델타에 더해야 한다(단일 정의 = rooms `design/components.md` §1.17). 안 더하면 chat 잠금 설정 시트에 권장 안내가 없다 — 어느 쪽인지 정해 기록.
2. **입장 시트 카운터 최대값.** `PromptSheet`는 `maxChars`가 필수라 카운터가 항상 보인다. 입장 입력 상한은 계약상 64(`ROOM_ENTER_PASSWORD_MAX`), 설정 상한은 32. 그림은 n/64로 두었다 — 확정은 설계자.
3. B 2줄 판의 포커스 순서는 DOM = 화면 순서(제목 → 취소 → 비밀번호 → 만들기). 제목 칸 Enter의 동작(만들기 제출 유지 vs 비밀번호로 이동)을 정해 둘 것.
4. 잠긴 행은 날짜 텍스트가 DOM에 없어야 한다(숨김 CSS 금지). 정렬은 서버 순서 그대로.
5. 입장 재요구 판의 ⋯·하단 바 미렌더는 (보완)이다 — 요구 문안과 대조해 채택 여부를 RTM에 적을 것.
6. `잠금 풀기` 항목·확인 버튼 색(danger 여부)은 정하지 않았다. 기존 danger는 데이터 삭제에만 썼다.
7. 「잠금」 메뉴 항목은 방 메뉴와 같은 토큰 분기(토큰 없으면 ⋯ 자체가 없음). 입장 시트만 읽기 전용에서도 뜬다.

## 9. 구조 제안(미채택) · 추가 후보

- 미채택: 상단 바 자물쇠, 비밀번호 확인 칸, 비밀번호 보기 토글(02 §15 · 인계 §3.6).
- 추가 후보(요구 없음 — 넣지 않음): 입장 시트 제목에 방 이름 표시(「비밀번호 · 비밀 다과회」). 어느 방에 들어가는지 확인용. 필요하면 요구 승격 후.
