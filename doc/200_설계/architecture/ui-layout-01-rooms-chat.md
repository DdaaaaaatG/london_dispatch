+----------------------------------------------+

### 2-1. 말풍선 메뉴 시트 (S1, 롱프레스 500ms·우클릭) — 약 232px
```
|  세바스찬 . 16:41  "예, 도련님."             |  머리 40px
|  수정                                        |  항목 44px
|  재작성                                      |  캐릭터 + 방의 마지막 메시지일 때만
|  삭제                                        |  danger → 확인 시트
|  취소                                        |  44px
```
### 2-2. ⋯ 방 메뉴 시트(약 232px) + 이름 변경 시트(약 180px)
```
|  방 메뉴 . 티타임        |   |  방 이름 변경                 |
|  이름 변경               |   |  [티타임              ]  3/60 |
|  장기기억                |   |  [ 취소 ]          [ 저장 ]   |
|  방 삭제 (danger)        |
|  취소                    |
```
### 2-3. 장기기억 편집 (M1, 전체 덮는 뷰)
```
| <  장기기억 . 티타임                  [저장] |  44px
| 마지막 갱신 10.05 16:30                      |  28px
| +------------------------------------------+ |  편집 flex 약 465px
| | (summary textarea)                       | |
| +------------------------------------------+ |
|                                   1240/4000  |  28px
```
로딩·오류는 편집 영역 자리에 StateView. 뒤로 시 변경 있으면 확인 시트.
### 2-4. 삭제 확인 (S1 confirm, 약 148px)
```
|  이 방을 삭제할까요?                         |
|  메시지와 장기기억이 함께 지워지며           |
|  되돌릴 수 없습니다.                         |
|  [ 취소 ]                       [ 삭제 ]     |  삭제 = danger 오른쪽
```
메시지 삭제도 같은 틀.

| 레이어 | 역할 | 컴포넌트 | 데이터 | 요구ID |
|---|---|---|---|---|
| ① 말풍선 메뉴 | 수정 · 재작성(조건부) · 삭제 | BottomSheet, SheetItem | regenerate, deleteMessage | R-CHAT-007 |
| ② 방 메뉴 / 이름 변경 | 이름 변경 · 장기기억 · 방 삭제 | BottomSheet, PromptSheet | renameRoom | R-CHAT-001, R-ROOM-003 |
| ③ 장기기억 | summary 보기·편집·저장 | TopBar, TextArea, StateView | getMemory, putMemory | R-CHAT-012 |
| ④ 확인 | 방·메시지 삭제 | ConfirmDialog | deleteRoom, deleteMessage | R-CHAT-001·007 |

읽기 전용 시 ①~④ 진입 경로·DOM 없음(장기기억 GET도 토큰 필요).

## 4. 크기 변화
- 폭 > 390: 바는 늘고 말풍선 최대 78%. 480 이상은 콘텐츠 최대 폭 480 중앙.
- 폭 ≤ 360: 상단 날짜 생략, 라벨 축약, 말풍선 85%.
- 높이 감소(키보드): 상단 44·하단 96 고정, 입력 1줄, 히스토리만 축소. 시트 최대 70%.
