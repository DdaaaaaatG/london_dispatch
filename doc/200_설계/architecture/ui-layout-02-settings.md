## 2. 탭별 폼 요소 (보완)

입력 종류 기준: 상한 80자 이하 = 한 줄 TextInput, 200자 이상 = 여러 줄 TextArea, 배열 = "한 줄에 하나" TextArea(줄 ↔ 배열 변환, 빈 줄 제거).
카운터 기준: TextInput은 입력 안 오른쪽, TextArea는 아래 오른쪽(공용 컴포넌트의 기존 위치, `counterMode="always"`). 배열 필드는 줄 수 카운터를 라벨 줄 오른쪽에 둔다. 넘치면 카운터가 danger 색이 되고 필드 아래에 안내 한 줄이 붙는다.

## 3. 하단 줄 D (보완)

```
| v3 저장됨 10.06 14:20      [되돌리기] [저장] |  clean        둘 다 비활성
| 기본값 사용 중             [되돌리기] [저장] |  isDefault    둘 다 비활성
| 저장하지 않은 변경 있음    [되돌리기] [저장] |  dirty        되돌리기 활성, 저장은 사전 검사 통과 시
| 저장 중...                 [되돌리기] [저장] |  saving       둘 다 비활성, 저장 busy
| 인증 만료                  [되돌리기] [저장] |  stale        저장 비활성 (되돌리기는 미해결 질문 1)
```
- 왼쪽 상태 문구 sm muted. dirty는 warning 색, stale은 danger 색. 한 줄 말줄임.
- 오른쪽 버튼은 md(36px). 「저장」 primary가 맨 오른쪽, 「되돌리기」 secondary가 그 왼쪽. 조건이 안 맞으면 미렌더가 아니라 **비활성**이다(자리 고정, 위치 학습 유지).
- 저장 활성 조건(인계 패킷 §3.2): dirty && 사전 검사 통과 && !saving && !stale.
- 「되돌리기」는 초안을 마지막으로 읽거나 저장한 값으로 되돌린다. 시드 복원(「기본값으로 되돌리기」)은 없다.

## 4. 상단 바 A — ⋯ 하나를 쓴다

결정: 내보내기·가져오기 진입은 **⋯ IconButton 1개 → ① 설정 파일 메뉴 시트**로 한다.

- ⋯는 ready·stale에서 렌더, loading·error에서는 미렌더(내보낼 값이 없다).
- 02 §5.3 초안의 상단 바 [저장]은 하단 줄로 옮겼다(위임문 지시). 초안의 하단 [⋯ 파일]은 상단 바 ⋯로 옮겼다.

### 5-3. ③ 가져오기 — 약 324px (오류 줄 있으면 약 360px)
```

|  가져오기                                    |  머리 40px
+----------------------------------------------+
|  [ 파일 선택 ]  선택한 파일 없음             |  44px. 버튼 secondary + 파일 이름 sm muted
```
