2. 대화창을 넣을 사이트 주소는 london-gossip.my 하나뿐인가요? www가 붙은 주소로도 들어오나요?

4. (완료 2026-10-08) Gemini API 키 — 지인 키, 지인이 **선불 결제(Pro)** 해 둠. 내가 별도 PowerShell에서 Cloudflare Secrets `LLM_API_KEY`에 직접 넣었음(클로드에겐 안 알려줌). 기본 모델 Pro 유지.

그리고 부탁 1개:

- Cloudflare 계정에 제가 직접 로그인해서 설정할 거라, 로그인 정보(이메일·비밀번호)를 카톡으로 보내 주세요. 2단계 인증(휴대폰 코드)이 걸려 있으면 로그인할 때 코드를 받아 알려 주셔야 합니다.

(2026-10-08 사용자 결정: 구성원 초대 방식 대신 **사용자가 지인 계정으로 직접 로그인**해 셋팅. 배포 명령 `wrangler login`은 이 PC 브라우저에서 지인 계정 로그인 창이 뜨므로, 그때 그 계정으로 들어가면 됨.)

(SECRET 비밀 문자열은 완성 파일 안에 들어가고, 파일은 카톡으로 보내기로 함. 2026-10-08 사용자 결정. 1회성 링크 절차 없음.)

참고(나만 알면 됨): 말풍선 버튼·패널(head.php·css·js)은 지인 사이트에 **이미 설치돼 있음**(2026-10-08 main.php에서 확인, 임베드 주소만 빈 값). 지인이 그 뒤 head.php를 더 꾸몄어도 상관없음. 지인이 보낸 `../chatbot update` 폴더의 head.php는 더 쓸 일 없음.

## 3. 지인 답이 오면 나에게 전달할 것

- 위 질문 4개의 답
- Cloudflare 로그인 정보(받았으면 "받았어"라고만. 비밀번호는 채팅에 안 적어도 됨 — 배포 때 브라우저 로그인 창이 뜨면 직접 입력)
- **운영용 Gemini API 키**(질문 4로 받은 것, 로컬에 넣은 키와 다른 것). 채팅에 그냥 붙여 주면 내가 Cloudflare Secrets에 넣고 채팅 기록엔 안 남긴다.

그러면 내가 `/deploy`로 배포하고, 지인에게 줄 **완성 파일 하나**(`rosebell-chatbot.php`, 33줄짜리)를 만들어 준다.
- 안에 대화창 주소 한 줄 + 회원 확인용 PHP 코드(SECRET 포함)가 채워져 있음
- 카톡으로 보내고, 지인은 호스팅 `theme/victorian/inc/` 자리에 덮어쓰기만 하면 됨
- 올린 뒤 갠홈에서 Ctrl+F5 → 말풍선 버튼 → 대화창이 뜨면 성공

## 4. 캐릭터 아이콘(인장) 넣는 법

지인이 세바스찬·시엘 아이콘을 다 그리면:

1. **파일 2개**를 받는다. 조건은 아래.
   - 형식: PNG (배경 투명 권장)
   - 모양: **정사각형**. 256×256 이상이면 충분(화면엔 28px 원으로 작게 보임)
   - 이름: `sebastian.png`, `ciel.png`
2. 나에게 "아이콘 왔어" 하고 파일을 준다(채팅에 첨부하거나 `D:\pr\dispatch\` 폴더에 넣고 경로 알려 주기).
3. 내가 `ui/public/img/sebastian.png`·`ui/public/img/ciel.png`를 그 파일로 바꾸고 → 커밋 → 재배포. 코드 수정 없음.
4. 배포 뒤 갠홈에서 Ctrl+F5 하면 말풍선 옆 원 안에 아이콘이 보인다.

지금은 그 자리에 투명 이미지 + 남색 바탕 원만 있다.
