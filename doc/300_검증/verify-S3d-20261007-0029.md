## ■ 중점 점검 결과 (리뷰어 보고 기준)

- **실명 노출 0건.** 투영 지점은 db/messages.ts toMessage 한 곳이다. 프롬프트·로그에 실명이 없고, D1에는 설계대로 실명이 저장된다.
- **'auto' 검증.** zod enum 정확 일치와 generate의 재확인으로 'Auto'·공백·유니코드 변형은 400이다.
- **타임아웃.** 선택 15초와 생성 51초로 LLM 합계 66초다(LLM_TIMEOUT_MS 60000 기준). speak 70초 상한과 잠금 90초 안이다.
- **모듈 경계.** select.ts는 순수 함수이고, 외부 호출은 client.ts의 selectSpeaker 한 곳이다.
- **예산 게이트와 잠금.** 예산 게이트가 잠금·선택보다 앞서고, 409면 AI 호출 0회다. 선택 실패는 기본 화자로 넘어가고 요청을 실패시키지 않는다.
- **로그.** 선택 로그에 응답 원문이 없다.
- **비용·레이트리밋.** 선택 호출도 비용 누적에 들어간다. 레이트리밋은 요청당 1회이고, 화면 자동 응답은 전송과 speak로 2회 카운트된다.
- **화면.** sendSucceeded는 한 번의 상태 갱신으로 처리되고 끼어들 경로가 0이다. 중립 pending('auto')은 기존 액션과 충돌하지 않는다. InlineEditor는 저장만 잠그고 취소·입력은 활성이며 aria-describedby가 연결된다.
- **경계 규칙.** 화면 소스의 fetch 직접 호출·토큰 저장 0건이다. 파일 최대 302줄, 함수 최대 48줄이다(서버 SRV-001 제외).
- **에러 코드 추가 0건.** 기존 테스트 변경은 설계 범위 안이다.
