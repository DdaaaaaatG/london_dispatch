# SECRET·비밀값 전달 절차

> 실값 없음 · 작성 2026-10-07 · 갱신 2026-10-08(AI 모델 선택) · 갱신 2026-10-08(완성 파일 카톡 전달·1회성 링크 폐기·API 키는 키 소유자 쪽이 직접 입력·Secrets 등록 완료) · 소유 contract-designer · 요구 R-HANDOFF-003 · R-ENV-002 🔒 · R-SET-001 🔒 · R-NFR-004 🔒
> **이 문서·채팅 본문·메일·스크린샷·커밋에 실제 SECRET·API 키·회원 아이디를 쓰지 않는다.** 이 문서의 `{{…}}`는 자리표시다.
> 2026-10-07 사용자 결정: 지인은 개발을 모른다. **SECRET은 우리가 만들고 넣는다.**
> 2026-10-08 사용자 결정: SECRET은 우리가 만든 **완성 `rosebell-chatbot.php` 파일 1개** 안에 넣어 **카카오톡 파일 첨부**로 보낸다. 지인은 그 파일을 같은 자리에 덮어쓰기만 한다. 1회성 비밀 링크 절차는 쓰지 않는다.

> **지인용 요약**
> 1. 카톡으로 받은 `rosebell-chatbot.php` 파일을 호스팅 `theme/victorian/inc/`에 같은 이름으로 덮어쓴다([embed-guide.md](embed-guide.md) 맨 위 요약).
> 2. 이 파일 안에는 **사이트 도장 비밀번호**가 들어 있다. 다른 사람에게 보내거나 다른 곳(메모·클라우드·다른 채팅방)에 옮겨 두지 않는다.
> 3. 올리고 확인이 끝나면 내 컴퓨터에 받은 파일은 지운다.

SECRET은 갠홈과 우리 서버가 함께 쓰는 **도장 비밀번호**다. 갠홈 PHP가 이 값으로 출입증(토큰)에 도장을 찍고, 서버는 같은 값으로 도장이 진짜인지 본다. 두 곳의 값이 **글자 하나까지 같아야** 한다. 이 값을 아는 사람은 아무 회원 이름으로나 글을 쓰고, 갠홈 주인 아이디로 캐릭터 설정까지 바꿀 수 있다. 그래서 따로 다룬다.

## 1. SECRET 규칙

| 규칙 | 이유 |
|---|---|
| **32자 이상**, 영문 대소문자와 숫자만(40자 이상 권장) | 서버는 32자 미만이면 모든 요청을 `500 CONFIG_INVALID`로 거절한다. 따옴표·공백·한글·특수문자는 PHP에 붙일 때 실수를 부른다 |
| **새로 만든 무작위 값** | 사람이 지은 문장·생일·사이트 이름은 안 된다 |
| 개발용 값(우리 PC의 `server/.dev.vars`)과 **다른 값** | 개발 값은 여러 사람·기계를 거친다. 운영 값은 운영 두 곳에만 둔다 |
| 테스트 값 `london-dispatch-test-secret-v1` 사용 금지 | 문서에 공개된 값이다(30자라 서버도 거부한다) |
| 운영 두 곳(Cloudflare·갠홈 PHP) 말고는 남기지 않는다 | 만든 메모·완성 파일 사본은 지인 확인이 끝나면 지운다 |

## 2. 기본 방식 — 우리가 만들어 완성 파일에 넣고 카톡으로 보낸다

| 순서 | 할 일 | 누가 | 상태 |
|---|---|---|---|
| 1 | 사용자가 지인 Cloudflare 계정으로 직접 로그인한다([cloudflare-setup.md](cloudflare-setup.md) §1) | 우리 | 완료 2026-10-08 |
| 2 | §3으로 SECRET을 만든다 | 우리 | 완료 2026-10-08 |
| 3 | Cloudflare Secrets `TOKEN_SECRET`에 넣는다(§4) | 우리 | 완료 2026-10-08 |
| 4 | **저장소 밖 로컬 임시 폴더**에서 완성 파일을 조립한다: 테마 원본에 운영 주소 줄 + 토큰 조각([token-snippet.php.md](token-snippet.php.md) §1 조립 순서). `{{SECRET}}` 자리는 SECRET 원본을 가진 사람(사용자)이 직접 채운다. LEVEL은 5 그대로 | 우리 | |
| 5 | 완성 파일을 카톡으로 지인에게 보낸다(아래 카톡 전달 규칙) | 우리 | |
| 6 | 호스팅 `theme/victorian/inc/`에 같은 이름으로 덮어쓰고 `Ctrl+F5` | 지인 | |
| 7 | 대조한다: 등급 5 이상 회원 계정으로 대화창을 열어 글쓰기 칸이 보이고 한 줄 써지는지 본다. 이상하면 그 페이지의 토큰을 `npm run token:test -w server -- verify`로 검사해 원인(서명·만료·등급)을 가른다(token-snippet §7) | 우리(필요하면 지인이 화면 확인) | |
| 8 | 지인 확인이 끝나면 내 컴퓨터의 완성 파일·SECRET 메모·셸 명령 기록을 지운다. 지인도 받은 파일을 지운다 | 우리 · 지인 | |

**카톡 전달 규칙**

- 완성 파일은 **파일 첨부**로 보낸다. 파일 내용을 대화창에 붙여 넣지 않고, SECRET 값을 채팅 본문에 따로 적지 않는다.
- 받는 사람은 지인 1명뿐이다. 단체방·다른 사람에게 보내지 않는다. 카톡이 `.php` 파일을 막으면 zip으로 묶어 보낸다.
- 전달·확인이 끝나면 우리 로컬 사본을 지운다. 지인은 업로드 뒤 받은 파일을 지우고 다른 곳에 저장하지 않는다.
- 파일이 다른 방·다른 사람에게 갔을 수 있으면 **SECRET을 새로 만들어**(§6) 다시 보낸다.

## 3. SECRET 만드는 법 (우리)

**가. Windows PowerShell**

```powershell
$b = New-Object byte[] 32; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b) -replace '[+/=]', ''
```

- 영문·숫자 40자 남짓이 한 줄 나온다. 32자 이상인지 센다(모자라면 다시 실행).

**나. openssl** (Git Bash 등)

```bash
openssl rand -hex 32
```

- 0~9·a~f로 된 64자가 나온다.

- 아무 웹사이트의 "랜덤 문자열 생성기"는 쓰지 않는다. 만든 값이 남의 서버를 거친다.

## 4. 양쪽 입력 위치

| 쪽 | 위치 | 누가 |
|---|---|---|
| Cloudflare | 아래 명령. 지인 계정으로 로그인한 터미널에서 실행하고, 값은 **물어볼 때 붙여 넣는다**(명령줄에 값을 치지 않는다) | 우리 |
| 갠홈 | 완성 파일 `theme/victorian/inc/rosebell-chatbot.php` 안 토큰 조각의 `define('RB_CHATBOT_SECRET', '…');` 줄. 우리가 채워서 보낸다 | 지인(덮어쓰기만) |

```bash
npx wrangler --config server/wrangler.toml secret put TOKEN_SECRET
```

- 화면으로 넣을 때는 Workers & Pages → `london-dispatch` → Settings → Variables and Secrets → Add → 종류 **Secret**. "Text"(평문)로 넣으면 다음 배포 때 지워지고 화면에도 보인다.

## 5. 함께 넣을 Secrets (모두 우리가 Cloudflare에 — 3개 등록 완료 2026-10-08)

| 이름 | 무엇 | 값의 출처·입력 | 비우면 |
|---|---|---|---|
| `TOKEN_SECRET` | 위 도장 비밀번호 | 우리가 만든다(§3). 완성 파일 안 SECRET과 같은 값 | 모든 요청 `500 CONFIG_INVALID` |
| `LLM_API_KEY` | Google Gemini API 키 | **지인 키**(지인이 Google에서 발급·선불 결제). 키를 받은 사용자가 **별도 터미널에서 직접** 입력한다(아래) | 읽기는 되고 캐릭터 버튼만 실패 |
| `OWNER_MB_IDS` | 캐릭터 설정 화면을 열 수 있는 **지인(갠홈 주인) 회원 아이디 1개** | 사용자를 거쳐 전달받음(값은 문서에 쓰지 않는다) | 설정 화면은 아무도 못 연다(전원 `403 OWNER_ONLY`). 대화는 기본 설정으로 계속 된다 |

- 지인이 Cloudflare에서 할 일은 없다.
- **`LLM_API_KEY` 입력 흐름(2026-10-08 완료)**: 키 값은 Claude 세션(채팅)을 거치지 않는다. 사용자가 Claude와 별개인 PowerShell 창에서 아래 명령을 실행하고, 물어볼 때 키를 붙여 넣었다. 키를 바꿀 때도 같은 방식으로 한다.

```bash
npx wrangler --config server/wrangler.toml secret put LLM_API_KEY
```

- `OWNER_MB_IDS` 값: **지인 회원 아이디 1개**(2026-10-07 사용자 결정). 닉네임이 아니라 **로그인 아이디**를 대소문자까지 그대로 넣는다(20자 이하). 서버 형식은 쉼표로 최대 5개까지 받지만 지금은 1개만 넣는다.
- 이 아이디는 이미 전달받았다. Secrets에 입력만 하고 문서·채팅에 다시 쓰지 않는다. 비밀번호는 아니지만 회원 아이디를 저장소에 남기지 않으려고 Secrets에 둔다.
- 이 세 개 말고 나머지 설정(등급·모델·한도 등)은 비밀이 아니어서 우리가 `server/wrangler.toml`에 적는다([cloudflare-setup.md](cloudflare-setup.md) §6).
- 그중 `LLM_MODEL`은 **주인이 캐릭터 설정 화면에서 AI 모델(Pro / Flash)을 고르기 전에 쓰는 기본 모델**(Pro)이고, `LLM_PRICE_*`는 **단가표에 없는 모델에만 쓰는 예비 단가**다. 어느 모델이든 키는 `LLM_API_KEY` 하나를 쓴다.

## 6. 교체 절차 (SECRET을 바꿀 때)

언제: 값이 새어 나갔을 수 있을 때, 완성 파일이 다른 사람·다른 방에 갔을 수 있을 때, 값을 잃어버렸을 때(Cloudflare는 넣은 값을 다시 보여 주지 않는다).

| 순서 | 할 일 | 누가 |
|---|---|---|
| 1 | §3으로 새 값을 만든다 | 우리 |
| 2 | 새 값으로 **새 완성 파일**을 만들어(token-snippet §1) 카톡으로 보낸다(§2 카톡 전달 규칙) | 우리 |
| 3 | 지인이 파일을 바로 올릴 수 있는 시간을 맞춘다 | 같이 |
| 4 | Cloudflare `TOKEN_SECRET`을 새 값으로 바꾼다 | 우리 |
| 5 | **곧바로** 새 완성 파일을 `theme/victorian/inc/`에 같은 이름으로 덮어쓴다 | 지인 |
| 6 | 회원으로 대화창을 새로 열어 글이 써지는지 본다 | 우리 |
| 7 | 옛 값·새 값 메모와 완성 파일 사본을 지운다. 지인도 받은 파일을 지운다 | 우리 · 지인 |

- 4번과 5번 사이에는 모두 읽기 전용이 된다(글쓰기 실패). 몇 분 안에 끝낸다. 회원이 적은 시간대가 좋다.
- 서버 값을 바꾸는 순간 옛 값으로 찍은 토큰은 **바로** 무효다. 그 회원은 다음 글쓰기에서 읽기 전용으로 바뀌고, 페이지를 새로 고치면 새 토큰으로 돌아온다.
- 옛 값이 새어 나갔더라도 그 값으로 만든 가짜 토큰은 교체 즉시 막힌다. 정상 토큰은 원래 12시간이면 만료된다.
- `LLM_API_KEY`를 바꿀 때: 지인에게 Google에서 새 키 발급을 부탁 → 키를 받은 사용자가 별도 터미널에서 `secret put LLM_API_KEY`로 직접 교체(Claude 채팅에 붙이지 않는다, §5) → 캐릭터 버튼 확인 → 지인이 Google에서 옛 키 삭제. 테마 파일은 그대로다.
- `OWNER_MB_IDS`를 바꿀 때: 우리가 Cloudflare 값만 바꾼다. 테마 파일은 그대로다.

## 7. 대안 — 지인이 직접 만들기 (기본 아님)

지인이 "SECRET을 아무에게도 넘기고 싶지 않다"고 할 때만 쓴다. 지인이 할 일이 늘어난다.

1. 지인이 §3 방법(또는 비밀번호 관리 앱 생성기, 길이 40·영문 대소문자·숫자만)으로 SECRET을 만든다.
2. 지인이 Cloudflare 화면(§4)에서 `TOKEN_SECRET`을 Secret 종류로 넣는다.
3. 우리가 SECRET 자리를 `{{SECRET}}` 그대로 둔 완성 파일을 보내고, 지인이 그 자리에 같은 값을 넣어 같은 자리에 올린다.
4. 지인이 "넣었다"고만 알린다. 우리는 값을 모르므로 대조는 실제 화면으로만 한다.

## 8. 하지 말 것

- SECRET·API 키를 채팅 본문·메일·문서·스크린샷·깃 커밋에 남기지 않는다. SECRET이 든 완성 파일을 지인에게 카톡 파일로 보내는 것만 예외다(§2).
- API 키를 Claude 세션 채팅에 붙이지 않는다(§5 입력 흐름).
- SECRET이 든 완성 파일을 지인 말고 다른 사람에게 보내지 않는다. 이 파일을 남에게 보여 줘야 하면 SECRET 줄을 `{{SECRET}}`로 바꾼 사본을 보낸다.
- 완성 파일을 저장소(`doc/`·`server/` 등) 안에 만들거나 두지 않는다.
- 테스트 값·개발 값을 운영에 쓰지 않는다.
- Cloudflare에 "Text"(평문) 종류로 넣지 않는다.
