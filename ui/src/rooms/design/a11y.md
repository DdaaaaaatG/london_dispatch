# rooms 상세 설계 — 접근성 (분할 문서)

> 주 문서: `ui/src/rooms/design.md`(RTM 포함). 이 파일은 주 문서 §9의 상세다.

| 항목 | 규칙 |
|---|---|
| 랜드마크 | 화면 루트 `<main aria-label="방 목록">`, 상단 바 `<header>`, 목록 영역 `<section>` |
| 제목 | TopBar `<h1 tabIndex={-1}>ROOMS</h1>`. RoomsScreen 마운트 시(첫 진입·‹ 뒤로 복귀) h1에 포커스 |
| 포커스 순서(읽기 전용) | h1(프로그램 포커스만) → 행 1 → 행 2 → … / 오류 상태면 「다시 시도」 |
| 포커스 순서(S2 쓰기) | h1 → 「+ 새 방」 → (열렸으면) 새 방 제목 입력 → 취소 → 만들기 → 행 1 → … |
| 포커스 순서(S3c 주인) | h1(제목) → ⚙ `캐릭터 설정` → 「+ 새 방」 → (열렸으면) 새 방 입력 행 → 행 1 → … . ⚙는 판정 응답 뒤에 생기며 생겨도 포커스를 옮기지 않는다. ⚙ = `button` 이름 `캐릭터 설정`(IconButton `aria-label`, SVG `aria-hidden`), Enter·Space = 설정 화면 진입. 설정에서 돌아오면 rooms 새 마운트로 h1 포커스 |
| 키보드 | Tab·Shift+Tab 이동, 행에서 Enter·Space = 진입. (S2) 「+ 새 방」 Enter·Space = 입력 행 열기 + 입력에 포커스. 입력에서 Enter = 만들기(한도 안일 때, IME 조합 중 제외), Esc = 취소(입력 행 닫고 「+ 새 방」에 포커스) |
| 역할 | 목록 `ul`/`li`, 행은 `button`. 행 `aria-label` = `{제목}, 마지막 갱신 {MM.DD}` |
| (S2) 새 방 | 「+ 새 방」 `button` 이름 `새 방 만들기`(보이는 글자 `+ 새 방`). 입력 행 `role="group" aria-label="새 방 만들기"`, 입력 `aria-label="새 방 제목"`, 한도 초과 시 `aria-invalid="true"`. 카운터는 `aria-hidden`(초과는 aria-invalid와 비활성 만들기로 전한다) |
| 상태 알림 | 로딩·빈 = `role="status"`(polite), 오류 = `role="alert"`. (S2) 생성 실패·읽기 전용 전환 토스트 = `role="alert"` |
| (S2) 전환 포커스 | 인증 실패로 쓰기 UI가 사라지면 h1로 포커스(F-RM-19) |
| 날짜 | `<time dateTime="YYYY-MM-DD">MM.DD</time>` |
| 포커스 링 | `:focus-visible` 2px `--color-focus` 바깥 |
| 대비 | 텍스트 4.5:1 이상(ui_design_concept §10). 상태를 색만으로 전달하지 않는다(문구 병행) |
| 모션 | 없음(목록·입력 행은 애니메이션 없음) |
| (S6) 잠긴 행 | 행 `button` 이름 = `{제목}, 잠긴 방`(날짜 없음, lock.md D-L4). 자물쇠 SVG `aria-hidden="true" focusable="false"`. 안 잠긴 행 이름은 불변. Enter·Space = 방 접근 판정(F-RM-41) |
| (S6) 새 방 2줄 포커스 | h1 → (⚙) → 「+ 새 방」 → 제목 입력 → 취소 → 비밀번호 입력 → 만들기 → 행 1 → …. 제목 Enter = 비밀번호 입력으로 포커스(제출 안 함), 비밀번호 Enter = 만들기(조건 맞을 때, IME 조합 중 제외), 두 입력 Esc = 취소(「+ 새 방」에 포커스) |
| (S6) 비밀번호 입력 | `<input type="password" aria-label="새 방 비밀번호">`, placeholder는 이름이 아니라 안내. 33자 이상이면 `aria-invalid="true"`. 카운터 `aria-hidden`. 보기 토글 없음 |
| (S6) 입장 시트 | BottomSheet `role="dialog" aria-modal="true" aria-label="비밀번호"`, h2 `비밀번호`. 열리면 입력(`aria-label="방 비밀번호"`, `type=password`)에 포커스. 실패 문구 `<p role="alert">`(바뀔 때마다 읽힘). Enter = 입장, Esc·덮개 = 취소(요청 중 막힘), Tab 트랩. 닫히면 열기 전 포커스(탭한 행)로 복귀. 성공이면 화면이 chat으로 바뀌어 chat h1 포커스 규칙을 따른다 |
| (S6) 조용한 입장 시도 | 진행 알림 없음(짧은 요청, lock.md D-L9). 실패로 시트가 열리면 시트 포커스 규칙 |
| (S6) 목록 다시 받기(`NOT_FOUND`) | 시트 닫힘 → `retry`로 loading `role=status` → 목록. 포커스는 BottomSheet 복귀 대상(행)이 사라졌으면 이동하지 않는다(기존 BottomSheet 규칙) |
