# rooms 상세 설계 — 접근성 (분할 문서)

> 주 문서: `ui/src/rooms/design.md`(RTM 포함). 이 파일은 주 문서 §9의 상세다.

| 항목 | 규칙 |
|---|---|
| 랜드마크 | 화면 루트 `<main aria-label="방 목록">`, 상단 바 `<header>`, 목록 영역 `<section>` |
| 제목 | TopBar `<h1 tabIndex={-1}>ROOMS</h1>`. RoomsScreen 마운트 시(첫 진입·‹ 뒤로 복귀) h1에 포커스 |
| 포커스 순서(읽기 전용) | h1(프로그램 포커스만) → 행 1 → 행 2 → … / 오류 상태면 「다시 시도」 |
| 포커스 순서(S2 쓰기) | h1 → 「+ 새 방」 → (열렸으면) 새 방 제목 입력 → 취소 → 만들기 → 행 1 → … |
| 키보드 | Tab·Shift+Tab 이동, 행에서 Enter·Space = 진입. (S2) 「+ 새 방」 Enter·Space = 입력 행 열기 + 입력에 포커스. 입력에서 Enter = 만들기(한도 안일 때, IME 조합 중 제외), Esc = 취소(입력 행 닫고 「+ 새 방」에 포커스) |
| 역할 | 목록 `ul`/`li`, 행은 `button`. 행 `aria-label` = `{제목}, 마지막 갱신 {MM.DD}` |
| (S2) 새 방 | 「+ 새 방」 `button` 이름 `새 방 만들기`(보이는 글자 `+ 새 방`). 입력 행 `role="group" aria-label="새 방 만들기"`, 입력 `aria-label="새 방 제목"`, 한도 초과 시 `aria-invalid="true"`. 카운터는 `aria-hidden`(초과는 aria-invalid와 비활성 만들기로 전한다) |
| 상태 알림 | 로딩·빈 = `role="status"`(polite), 오류 = `role="alert"`. (S2) 생성 실패·읽기 전용 전환 토스트 = `role="alert"` |
| (S2) 전환 포커스 | 인증 실패로 쓰기 UI가 사라지면 h1로 포커스(F-RM-19) |
| 날짜 | `<time dateTime="YYYY-MM-DD">MM.DD</time>` |
| 포커스 링 | `:focus-visible` 2px `--color-focus` 바깥 |
| 대비 | 텍스트 4.5:1 이상(ui_design_concept §10). 상태를 색만으로 전달하지 않는다(문구 병행) |
| 모션 | 없음(목록·입력 행은 애니메이션 없음) |
