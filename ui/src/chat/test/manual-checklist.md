- **S4**: MC-CH-21·22는 유효 토큰 주소가 필요하다. 시드 방 2개(장기기억 요약 있음 · 빈 요약)를 준비한다. 요약은 서버 자동 요약이 아직 없으면 시트에서 직접 저장해 만든다. 저장 실패 화면은 개발 서버 중지(`NETWORK`)로 만든다.
- S3 항목(MC-CH-16~18)은 유효 토큰 주소 + 서버 `LLM_API_KEY`가 필요하다. 실패 화면은 개발 서버의 가짜 제공자(fake) 또는 키를 비운 상태(`CONFIG_INVALID`)로 만든다.
- 묶음: S1(읽기 전용 판) + **S2(쓰기 판·시트·전환)**. 자동화가 불가능한 항목(실제 렌더 크기·폰트·색 토큰·실제 스크롤·터치 체감·스크린 리더·코드 리뷰 grep)만 둔다. S2 항목은 유효·등급 미달 토큰이 붙은 `?t=` 주소가 필요하다(개발 서버에서 발급 방법은 `doc/handoff/` 기준).
