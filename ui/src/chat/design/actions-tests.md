## 11.1 신규 TC (TC-CH-110 ~ 121)

공통 준비: `vi.mock('@/api')` **불변**(`editMessage`·`deleteMessage`·`regenerate`·`speak`·`appendUser`·`listMessages` 그대로). 쓰기 TC는 `WRITER_VIEWER`.

**스펙 전제(v2.0.1, 구현·스펙 실물).**
- **질의 범위.** 같은 이름의 그룹·버튼이 여러 개다(같은 화자 말풍선이 여럿). 그룹은 그 말풍선의 `<li>`로 범위를 줄인 뒤 찾는다: `within(li).getByRole('group', { name: '세바스찬 말풍선 작업' })` → `within(group).getByRole('button', { name: '세바스찬 대사 수정' })`.
- **포커스 판별.** 공용 Button 루트 클래스 키 `root`가 다른 모듈의 `root`(예: Bubble)와 non-scoped 테스트 클래스에서 겹친다. 그래서 "포커스가 버튼에 있다"는 클래스가 아니라 `document.activeElement?.tagName === 'BUTTON'` + 접근 이름으로 판별한다.
