# chat 상세 설계 — 접근성 (분할 문서)

> 주 문서: `ui/src/chat/design.md`(RTM 포함). 이 파일은 주 문서 §9의 상세다.

| 항목 | 규칙 |
|---|---|
| 랜드마크 | `<main aria-label="대화: {방 제목}">`, `<header>`(TopBar), 히스토리 `<section>`. (S2) 하단 바 `role="group" aria-label="메시지 작성"` |
| 제목 | TopBar `<h1>` = 방 제목(이름 변경 시 바로 바뀐다). 생성일 `<time dateTime="YYYY-MM-DD" aria-label="방 생성일 MM.DD">MM.DD</time>` |
| 마운트 포커스 | ‹ 뒤로 버튼(`backButtonRef`) |
| 포커스 순서(읽기 전용) | ‹ 뒤로 → 히스토리 스크롤 박스(`tabIndex=0`) → B0 「다시 시도」(있을 때) → B1 배지(있을 때). 첫 로드 오류면 ‹ 뒤로 → 「다시 시도」 |
| 포커스 순서(S2·S3 쓰기) | ‹ 뒤로 → ⋯ → 히스토리 스크롤 박스 → **(S3e) 말풍선마다 버튼 줄 「수정」→(「재작성」)→「삭제」(위→아래, 말풍선 자체는 Tab 대상 아님 — 옛 `tabIndex=0` 삭제)** → (S3) 실패 말풍선 「재시도」(있을 때, 목록 끝) → B0·B1 → **(S3) 세바스찬 → 시엘** → OOC 토글 → 입력창 → 전송 (ui-design-strategy §6.7). 임시 말풍선(생성 중)은 포커스를 받지 않는다 |
| 키보드(S2) | 입력창 Enter = 전송, Shift+Enter = 줄바꿈, IME 조합 중 Enter 무시. ~~말풍선 Shift+F10·메뉴 키 = 말풍선 메뉴~~(S3e 삭제 — 버튼 줄 Enter·Space). 시트 Esc = 닫기(요청 중 제외), Tab 순환(포커스 트랩). 인라인 수정 Esc = 취소, Enter = 줄바꿈. 이름 변경 입력 Enter = 저장(유효·바뀜일 때) |
| 키보드(S3) | 캐릭터 버튼·「재시도」는 Enter·Space(네이티브 `<button>`). 재작성은 (S3e) 말풍선 아래 「재작성」 버튼(Enter·Space). 생성에는 단축키를 두지 않는다. (S3d) 입력창 Enter = 전송이고, 저장이 성공하면 자동 응답이 이어진다(R-CHAT-006 🔒 개정). 저장 중·생성 중 Enter는 무시된다(쓰기 잠금) |
| (S3d) 잠긴 저장 버튼 | 생성 중 인라인 수정 저장 버튼은 네이티브 `disabled` + `aria-describedby` → 숨은 안내 `응답을 만드는 중에는 저장할 수 없습니다`(`labels.editSaveLockedNote`). 잠금 해제 시 안내 미렌더. 취소 버튼·입력은 활성(`design/auto.md` §7, D-17) |
| (S3d) 중립 말풍선 | 상세는 `design/auto.md` §7. 생성 중: 루트 `role="status" aria-live="polite"`, 숨은 안내 `응답을 만드는 중`(`…`는 `aria-hidden`), 아바타·이름 없음, 포커스 받지 않음. 실패: 문구 `<p role="alert">`, 「재시도」 접근 이름 `응답 재시도`(보이는 글자 `재시도` 포함 — label-in-name), 네이티브 `disabled`로 잠금. 포커스: 전송 뒤 입력창 유지, 자동 생성의 시작·결과·실패는 포커스를 옮기지 않는다. 중립 「재시도」를 누르면 버튼이 사라지기 전에 히스토리 스크롤 박스로 옮긴다(F-CH-32, D-19). 잠금 해제 때 캐릭터 버튼으로 끌어오지 않는다(`speakingCharacterOf`가 `'auto'`에 null). 읽기 전용이면 미렌더 |
| 히스토리 역할 | 스크롤 박스 `role="log" aria-live="polite" aria-label="대화 기록"`, 이전 페이지 로드 중 `aria-busy="true"`. 새 발화는 log의 polite 알림으로 읽힌다(S3 speak 결과 포함) |
| ~~(S2) 말풍선 메뉴 대상~~ → (S3e) 말풍선 버튼 줄 | **삭제(S3e)**: 말풍선에 `tabIndex`·`aria-haspopup`·`aria-keyshortcuts` 없음. 대신 쓰기 가능일 때 버튼 줄 `role="group"` `{이름} 말풍선 작업` · 버튼 `{이름} 대사 수정/재작성/삭제`(label-in-name) · 잠금은 네이티브 `disabled`. 임시·실패 말풍선에는 없음. 포커스 목적지: 편집 닫힘 → 그 말풍선 「수정」(disabled면 log) · 삭제 취소·실패 → 「삭제」 · 재작성 성공·일반 실패 → 「재작성」 — 상세 `design/actions.md` §7 |
| (S2) 시트 | `role="dialog"`(방 메뉴 `방 메뉴`, 이름 변경 `방 이름 변경`. 말풍선 메뉴 `메시지 메뉴`는 S3e 삭제) · 확인은 `role="alertdialog"`(이름 = 질문 문구) · `aria-modal="true"`. 열릴 때 첫 항목(확인은 **취소**, 이름 변경은 입력)에 포커스, 닫히면 연 버튼·말풍선으로 복귀. 대상이 사라졌으면(메시지 삭제) 히스토리 스크롤 박스로(F-CH-30) |
| (S2) 상태 알림 | 하단 바 전송 중 `aria-busy="true"`. E 토스트 `role="alert"`. 이름 변경 실패 문구 `role="alert"`. 입력 한도 초과 `aria-invalid="true"` |
| (S3) 생성 중 알림 | 임시 말풍선 루트 `role="status" aria-live="polite"`, 읽는 문구 `세바스찬 대사를 만드는 중`(시각적 `…`는 `aria-hidden`, 문구는 지역 `.srOnly`). 생성 실패로 바뀌면 문구 `<p role="alert">`가 즉시 읽힌다 |
| (S3) 재작성 중 알림 | 대상 말풍선 본문 `aria-busy="true"` + 머리 줄 `<span role="status">다시 쓰는 중…</span>`. busy는 본문에만 건다(같은 말풍선 안 status 알림이 미뤄지지 않게) |
| (S3) 잠금 | 생성·재작성·다른 쓰기 중 캐릭터 버튼 2·「재시도」·전송은 네이티브 `disabled`(공용 Button `isDisabled`). 접근성 트리에 비활성으로 노출된다. `aria-disabled`는 따로 붙이지 않는다(네이티브 `disabled`와 중복 — ARIA 첫 규칙, 공용 Button 변경 없음). 입력창은 잠그지 않는다(타이핑 가능) |
| (S3) 포커스 유지 | 누른 캐릭터 버튼이 `disabled`가 되며, 또는 「재시도」 버튼이 언마운트되며 포커스를 잃으면(활성 요소가 `body`), 잠금이 풀린 순간 **그 생성의 캐릭터 버튼**으로 포커스를 돌린다(F-CH-38, DC-03 — 「재시도」의 목적지 = 같은 캐릭터 SpeakButton). 사용자가 그사이 다른 곳으로 옮겼으면 건드리지 않는다. 재작성은 (S3e) 잠금이 풀릴 때 같은 「재작성」 버튼으로(F-CH-51, 옛 "시트가 닫히며 연 말풍선으로"). `NOT_LAST_MESSAGE` 재조회·대상 사라짐이면 **재조회·제거가 ready로 커밋된 뒤** 히스토리 스크롤 박스로, 0건이라 log가 없으면 ‹ 뒤로(F-CH-36 · F-CH-41, CF-01). 잠금이 풀릴 때 복귀 대상 기억은 매번 비운다(F-CH-38) |
| (S2) 전환 | 인증 실패로 쓰기 UI가 사라지면 ‹ 뒤로에 포커스(F-CH-29), 토스트가 이유를 읽어 주고 D `role="note"`가 남는다. (S3) 임시·실패 말풍선도 같은 커밋에서 사라진다 |
| 상태 알림(S1) | 첫 로드 loading·empty `role="status"`, 오류 `role="alert"`. B0 loading `role="status"`, error `role="alert"`. D `role="note"` |
| 버튼 레이블(R-CHAT-013) | ‹ = `방 목록으로 돌아가기`, ⋯ = `방 메뉴 열기`, 배지 = `새 메시지 보기, 맨 아래로 이동`, OOC 스위치 = `OOC 지시 모드`(+`aria-checked`), 입력창 = `메시지 입력`, 전송·「다시 시도」·시트 항목 = 보이는 글자. (S3) 캐릭터 버튼 = `세바스찬 대사 생성`·`시엘 대사 생성`(보이는 글자 `세바스찬`·`시엘`을 이름 앞에 포함 — label-in-name), 「재시도」 = `세바스찬 대사 재시도`·`시엘 대사 재시도`. (S3e) 말풍선 버튼 = `{이름} 대사 수정`·`{이름} 대사 재작성`·`{이름} 대사 삭제`(옛 재작성 시트 항목 삭제) |
| 이미지 | 아바타 `alt=""`(임시·실패 말풍선 포함) |
| 장식 | OOC `—`·배지 화살표·‹·⋯ 아이콘 SVG·입력 카운터·(S3) 임시 `…`·실패 `!`는 `aria-hidden="true"` |
| 화자 구분 | 색 + 이름 + 정렬 세 가지. OOC 토글은 색 + 글자(`OOC 켬`/`OOC 끔`). (S3) 실패 말풍선은 테두리 색 + `!` + 문구(색만으로 구분하지 않음) |
| 대비 | 텍스트 4.5:1 이상(시트·토스트 바탕 위 포함). (S3) 재작성 중 흐린 본문(opacity 0.55)은 일시 상태이며 `다시 쓰는 중…` 글자로 상태를 함께 알린다. 흐림 대비는 가짜 제공사가 즉시 응답해 자동 캡처가 안 되므로 **수동 확인 항목**(TC-CH-092, v1.7.1) |
| 포커스 링 | `:focus-visible` 2px `--color-focus` 바깥(스크롤 박스·말풍선 포함) |
| 모션 | `prefers-reduced-motion: reduce`면 페이드·시트 이동 0ms. 스크롤 이동은 항상 즉시. (S3) 임시 말풍선에 애니메이션 없음 |
