# chat 상세 설계 — 접근성 (분할 문서)

> 주 문서: `ui/src/chat/design.md`(RTM 포함). 이 파일은 주 문서 §9의 상세다.

| 항목 | 규칙 |
|---|---|
| 랜드마크 | `<main aria-label="대화: {방 제목}">`, `<header>`(TopBar), 히스토리 `<section>`. (S2) 하단 바 `role="group" aria-label="메시지 작성"` |
| 제목 | TopBar `<h1>` = 방 제목(이름 변경 시 바로 바뀐다). 생성일 `<time dateTime="YYYY-MM-DD" aria-label="방 생성일 MM.DD">MM.DD</time>` |
| 마운트 포커스 | ‹ 뒤로 버튼(`backButtonRef`) |
| 포커스 순서(읽기 전용) | ‹ 뒤로 → 히스토리 스크롤 박스(`tabIndex=0`) → B0 「다시 시도」(있을 때) → B1 배지(있을 때). 첫 로드 오류면 ‹ 뒤로 → 「다시 시도」 |
| 포커스 순서(S2 쓰기) | ‹ 뒤로 → ⋯ → 히스토리 스크롤 박스 → 말풍선들(`tabIndex=0`, 위→아래) → B0·B1 → OOC 토글 → 입력창 → 전송 (ui-design-strategy §6.7. 캐릭터 버튼은 S3에서 OOC 앞에 들어간다) |
| 키보드(S2) | 입력창 Enter = 전송, Shift+Enter = 줄바꿈, IME 조합 중 Enter 무시. 말풍선 Shift+F10·메뉴 키 = 말풍선 메뉴. 시트 Esc = 닫기(요청 중 제외), Tab 순환(포커스 트랩). 인라인 수정 Esc = 취소, Enter = 줄바꿈. 이름 변경 입력 Enter = 저장(유효·바뀜일 때) |
| 히스토리 역할 | 스크롤 박스 `role="log" aria-live="polite" aria-label="대화 기록"`, 이전 페이지 로드 중 `aria-busy="true"`. 새 발화는 log의 polite 알림으로 읽힌다 |
| (S2) 말풍선 메뉴 대상 | 쓰기 가능일 때만 말풍선 `tabIndex=0` · `aria-haspopup="dialog"` · `aria-keyshortcuts="Shift+F10"` |
| (S2) 시트 | `role="dialog"`(말풍선 메뉴 `메시지 메뉴`, 방 메뉴 `방 메뉴`, 이름 변경 `방 이름 변경`) · 확인은 `role="alertdialog"`(이름 = 질문 문구) · `aria-modal="true"`. 열릴 때 첫 항목(확인은 **취소**, 이름 변경은 입력)에 포커스, 닫히면 연 버튼·말풍선으로 복귀. 대상이 사라졌으면(메시지 삭제) 히스토리 스크롤 박스로(F-CH-30) |
| (S2) 상태 알림 | 하단 바 전송 중 `aria-busy="true"`. E 토스트 `role="alert"`. 이름 변경 실패 문구 `role="alert"`. 입력 한도 초과 `aria-invalid="true"` |
| (S2) 전환 | 인증 실패로 쓰기 UI가 사라지면 ‹ 뒤로에 포커스(F-CH-29), 토스트가 이유를 읽어 주고 D `role="note"`가 남는다 |
| 상태 알림(S1) | 첫 로드 loading·empty `role="status"`, 오류 `role="alert"`. B0 loading `role="status"`, error `role="alert"`. D `role="note"` |
| 버튼 레이블(R-CHAT-013) | ‹ = `방 목록으로 돌아가기`, ⋯ = `방 메뉴 열기`, 배지 = `새 메시지 보기, 맨 아래로 이동`, OOC 스위치 = `OOC 지시 모드`(+`aria-checked`), 입력창 = `메시지 입력`, 전송·「다시 시도」·시트 항목 = 보이는 글자 |
| 이미지 | 아바타 `alt=""` |
| 장식 | OOC `—`·배지 화살표·‹·⋯ 아이콘 SVG·입력 카운터는 `aria-hidden="true"` |
| 화자 구분 | 색 + 이름 + 정렬 세 가지. OOC 토글은 색 + 글자(`OOC 켬`/`OOC 끔`) |
| 대비 | 텍스트 4.5:1 이상(시트·토스트 바탕 위 포함) |
| 포커스 링 | `:focus-visible` 2px `--color-focus` 바깥(스크롤 박스·말풍선 포함) |
| 모션 | `prefers-reduced-motion: reduce`면 페이드·시트 이동 0ms. 스크롤 이동은 항상 즉시 |
