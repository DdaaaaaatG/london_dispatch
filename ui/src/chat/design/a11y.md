# chat 상세 설계 — 접근성 (분할 문서)

> 주 문서: `ui/src/chat/design.md`(RTM 포함). 이 파일은 주 문서 §9의 상세다.

| 항목 | 규칙 |
|---|---|
| 랜드마크 | `<main aria-label="대화: {방 제목}">`, `<header>`(TopBar), 히스토리 `<section>` |
| 제목 | TopBar `<h1>` = 방 제목. 생성일 `<time dateTime="YYYY-MM-DD" aria-label="방 생성일 MM.DD">MM.DD</time>` |
| 마운트 포커스 | ‹ 뒤로 버튼(`backButtonRef`) |
| 포커스 순서(S1) | ‹ 뒤로 → 히스토리 스크롤 박스(`tabIndex=0`, 방향키·PageUp/PageDown 스크롤) → B0 「다시 시도」(있을 때) → B1 배지(있을 때). 첫 로드 오류면 ‹ 뒤로 → 「다시 시도」 |
| 키보드 | Tab·Shift+Tab 이동, 버튼 Enter·Space. S1에는 Esc·Enter 전송·Shift+F10 대상이 없다(시트·입력·말풍선 메뉴 없음) |
| 히스토리 역할 | 스크롤 박스 `role="log" aria-live="polite" aria-label="대화 기록"`, 이전 페이지 로드 중 `aria-busy="true"` |
| 상태 알림 | 첫 로드 loading·empty `role="status"`, 오류 `role="alert"`. B0 loading `role="status"`, error `role="alert"`. D `role="note"` |
| 버튼 레이블(R-CHAT-013) | ‹ = `방 목록으로 돌아가기`, 배지 = `새 메시지 보기, 맨 아래로 이동`, 「다시 시도」 = 보이는 글자 |
| 이미지 | 아바타 `alt=""`(이름이 바로 옆에 텍스트로 있다) |
| 장식 | OOC `—`·배지 화살표 SVG·‹ 아이콘 SVG는 `aria-hidden="true"` |
| 화자 구분 | 색 + 이름 + 정렬 세 가지(ui_design_concept §10). 색만으로 구분하지 않는다 |
| 대비 | 텍스트 4.5:1 이상(말풍선 바탕 위 포함) |
| 포커스 링 | `:focus-visible` 2px `--color-focus` 바깥(스크롤 박스 포함) |
| 모션 | `prefers-reduced-motion: reduce`면 페이드 0ms. 스크롤 이동은 항상 즉시 |
